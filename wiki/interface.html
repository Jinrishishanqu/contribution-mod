界面操作

贡献值、股票和商店各有图形界面。安装模组的客户端使用专用页面，原版客户端使用原版对话界面。

  2. 贡献值页面
  3. 筛选与分页
  4. 返回与关闭
  5. 显示与滚动
  6. 补充资料

打开界面

输入 /contribution 或 /contribution ui 打开贡献值首页，输入 /stock 打开股票市场，输入 /shop 打开商店。安装客户端模组后使用专用页面，原版客户端使用 Minecraft 26.3 原版对话界面。

两种界面读取同一套服务端数据和权限。文字命令同时可用，控制台使用文字查询与管理命令。

贡献值页面

页面内容与交互
首页我的账户与统计、我的流水、行业建设度、每日签到与活动；管理员额外显示「管理员功能」入口。
签到今日在线秒数与自动签到状态、活动期限和奖励；可点击领取活动奖励
管理员功能输入框下直接显示可点击的账户列表；客户端输入后延迟 450 毫秒按名称前缀或完整唯一标识符搜索，原版对话界面提供筛选按钮；全服流水与查询玩家保留
账户与统计合并余额、历史总收入、唯一标识符、原始放置、挖掘和个人总建设度；九行业个人建设度每行三个，共三行；支持刷新、查看流水、返回上级和首页
行业总览首行为行业、当日、总建设度、繁荣度、核算日的标题；九行业各占一行。繁荣度显示时四舍五入保留两位小数，数据库精度不变
账户列表管理员按名称分页，图形界面每页 8 个账户，可点击进入详情
流水图形界面每页 8 条，首行显示时间、玩家、变动、余额、类型和原因的列标题，每笔流水只占一行

管理员通过 /contribution add 和 /contribution remove 修改余额，图形页面用于查询与浏览。

筛选与分页

  • 客户端流水页可点选「全部」「股票买入」「股票卖出」等常用筛选；原版流水页保留「全部流水」「股票买入」「股票卖出」「管理员调整」「退市返还」按钮。
  • 其他筛选仍可使用 type/source/server/from/to 的 名称=值 高级格式，与文字命令共享解析及权限。
  • 筛选日期按 UTC 日界线计算并包含结束日期，界面会注明该区别。
  • 普通玩家只能查询本人最近 90 天；管理员可查历史归档，单次最多 365 天。
  • 分页游标历史独立存储，只有「上一页」使用该历史；Esc 不返回上一页流水。

返回与关闭

  • 按 Esc 返回当前页面的上级；首页按 Esc 关闭界面。
  • 「上一页」「下一页」只用于翻页，翻页后上级保持不变。
  • 贡献值页面底部提供「返回上级」「首页」「关闭」。
  • 股票详情和持仓返回市场，商店编辑返回商品管理，商品管理返回商店。

显示与滚动

账户页按账户摘要、原始操作次数和行业建设度分区显示。超出页面高度时使用鼠标滚轮，滚动条显示当前位置。账户和活动行支持点击、悬停提示与键盘聚焦。专用界面打开时，单人世界继续运行。

页面会话与异步更新

同一模块刷新、翻页和搜索时复用页面及可见行控件，保留输入与焦点。每位玩家的 PageSession 保存页面版本及在途读取，查询结果同时匹配会话和版本后才应用。
