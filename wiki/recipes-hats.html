制作

在锻造台以线作模板，放入指定基底和外形材料。帽子的属性与保留数据取决于基底。

表中数量均为单次制作所需。服务端加载世界时启用内置配方，外观通过资源包显示。

铁砧外观帽子（皮革帽子底材）

产物：皮革帽子 × 1。

锻造槽材料数量
左：模板线1
中：基底皮革帽子1
右：附加材料铁砧1

取走结果时，各槽消耗一件材料，包括模板。结果继承基底数据，再应用配方指定的属性与外观。

结果属性与组件
{
  "minecraft:item_model": "minecraft:anvil",
  "minecraft:max_stack_size": 1,
  "minecraft:lore": [
    {
      "text": "变形帽子",
      "italic": false,
      "color": "gray"
    }
  ],
  "minecraft:equippable": {
    "slot": "head"
  }
}
配方数据

配方标识符：contribution:items/hats/anvil；产物物品标识符：minecraft:leather_helmet。结果组件在继承基底数据后应用。

{
  "type": "minecraft:smithing_transform",
  "template": "minecraft:string",
  "base": "minecraft:leather_helmet",
  "addition": "minecraft:anvil",
  "result": {
    "id": "minecraft:leather_helmet",
    "components": {
      "minecraft:item_model": "minecraft:anvil",
