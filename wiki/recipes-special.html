特殊道具配方

公示喇叭用于展示副手物品，哑炮用于播放点燃音效，两者均通过工作台合成。

  1. 制作
  2. 哑炮
  3. 公示喇叭

制作

按图放入材料。用法、消耗和冷却见特殊道具。

表中数量均为单次制作所需。服务端加载世界时启用内置配方，外观通过资源包显示。

哑炮

产物：哑炮 × 8。

材料数量
火药8
水桶1

一次制作 8 个哑炮，水桶返还为空桶。

结果属性与组件
{
  "minecraft:item_name": {
    "text": "哑炮"
  },
  "minecraft:rarity": "uncommon",
  "minecraft:custom_data": {
    "contribution:item": "dud"
  },
  "minecraft:consumable": {
    "animation": "none",
    "consume_seconds": 0.1,
    "has_consume_particles": false,
    "sound": "minecraft:entity.creeper.primed"
  },
  "minecraft:use_cooldown": {
    "seconds": 1,
    "cooldown_group": "contribution:dud"
  }
}
