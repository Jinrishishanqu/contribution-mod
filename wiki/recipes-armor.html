主题盔甲配方

马克六型、纳米和量子盔甲提供三套主题外观，每套包括四件普通部件和一件翼装胸甲。

制作

普通部件由下界合金装备与主题材料无序合成；翼装胸甲在锻造台制作，槽位见各配方。

表中数量均为单次制作所需。服务端加载世界时启用内置配方，外观通过资源包显示。

马克六型靴子

产物：马克六型靴子 × 1。

无序合成材料数量
下界合金靴子1
铁锭1

把装备与主题材料放入任意两个合成格，取出结果。转化继承基底数据，并设置对应的主题外观。

普通主题部件改变名称和外观，战斗性能沿用基底，已有滑翔能力保留。可见翅膀使用本套翼装胸甲配方。

结果属性与组件
{
  "minecraft:item_name": {
    "text": "Mark 6靴子"
  },
  "minecraft:rarity": "epic",
  "minecraft:item_model": "contribution:armor/mark_6_boots",
  "minecraft:equippable": {
    "slot": "feet",
    "asset_id": "contribution:armor/mark_6",
    "equip_sound": "minecraft:item.armor.equip_netherite"
  }
}
配方数据
