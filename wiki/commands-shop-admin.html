商店管理命令

商店管理命令用于创建商品、修改商品信息和上下架，也可打开完整的管理表单。

  1. 使用
  2. 示例
  3. 本模块命令路径

使用

商店管理需要管理员等级 2。/shop admin 打开图形管理界面；put_on、take_off、modify 提供文字入口，publish / save 是图形表单的提交命令。

  • put_on 自动分配稳定、不可复用的商品编号，排序默认 0。
  • modify 按名称、数量、售价、描述的顺序填写；只改后面的字段时前面填 -，未填写的尾部字段保持不变，描述填 "" 清空。
  • save 必须携带编辑页加载的实际 revision，其他管理员已经修改时拒绝覆盖。
  • 物品参数使用原版物品参数，可以携带数据组件；完整定义最多 2048 字符。
  • take_off 只下架，不删除商品、历史订单或待发物品。
  • 目录最多保留 256 件商品（含已下架商品）。

示例

/shop admin
/shop modify 1 - - 35
/shop take_off 1

/shop admin publish <item> <name> <count> <price> <order> <listed> <description>

功能
提交完整新商品表单，设置物品、排序、状态和描述。
权限
管理员
示例
/shop admin publish minecraft:torch "火把" 16 20 0 true "照明"
参数与限制
物品可带组件；数量 1—64、售价≥1，排序为整数，上架状态：true 为上架，false 为下架。
原版参数类型item: 原版物品[数据组件]; name: 字符串（空格需引号）; count: integer(1, 64); price: integer(1); order: integer(); listed: true|false; description: 字符串（空格需引号）;

/shop admin save <id> <revision> <item> <name> <count> <price> <order> <listed> <description>

功能
保存已有商品完整字段，拒绝过期编辑版本。
权限
管理员
示例
/shop admin save 1 0 minecraft:torch "火把" 16 20 0 true "照明"
参数与限制
revision 必须使用编辑页加载的实际版本；此例 0 只适用于版本 0 商品。
原版参数类型id: longArg(1); revision: longArg(0); item: 原版物品[数据组件]; name: 字符串（空格需引号）; count: integer(1, 64); price: integer(1); order: integer(); listed: true|false; description: 字符串（空格需引号）;

/shop put_on <legacy_item> <name> <count> <price>

功能
上架商品，自动分配不可复用编号。
权限
管理员
示例
/shop put_on minecraft:torch "火把" 16 20 照明用品
参数与限制
支持 item <物品及组件>或 hand_item（玩家主手完整组件快照，不消耗）；旧直接物品语法兼容。每份数量 1—64，与手持数量独立；售价正整数，名称≤64 字、描述≤512 字，组件定义≤2048 字符。
原版参数类型legacy_item: 原版物品[数据组件]; name: 字符串（空格需引号）; count: integer(1, 64); price: integer(1);
