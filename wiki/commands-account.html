账户管理命令

账户管理命令用于增减余额、创建账户、迁移唯一标识符和清理假人账户，需要管理员权限。

  1. 使用
  2. 示例
  3. 本模块命令路径

使用

这一组是管理员专用的经济操作入口。所有命令都在服务端的同一数据库事务内完成账户更新与流水写入，并遵守余额范围与幂等约束。

  • add / remove 的金额分别为 1—2147483647 与 1—2147483648；布尔参数决定是否同步影响历史总收入。
  • 目标支持玩家名称、唯一标识符或玩家选择器；选择器必须恰好选中一名玩家，多目标选择器会被拒绝。
  • 每次命令先返回请求标识符与可点击的原请求重试文本，再异步执行。
  • retry 必须使用完全相同的目标、金额、原因、收入标志与备注，否则视为幂等冲突。
  • account migrate 只允许在主服务器控制台且没有在线玩家时执行，执行前必须备份。
  • bot_check 是破坏性清理，不会回滚已计入服务器建设度的历史汇总。
⚠
重试使用原请求结果不明时使用 /contribution retry <原请求UUID> …，不要重新执行 add / remove，否则会生成新的幂等标识符并可能重复变动余额。

示例

/contribution add Steve 100 服务器活动 true
/contribution remove Steve 20 商店调整 false

本模块命令路径

共 12 条命令路径，权限、示例与参数要求列在各条目中。

/contribution account create <uuid> <name>

功能
创建账户；安全迁移唯一标识符身份及关联数据。
权限
管理员；migrate 仅主服控制台且没有在线玩家
示例
/contribution account create <唯一标识符> PlayerName
参数与限制
migrate 必须 confirm，源/目标身份及目标数据均校验；先备份。
原版参数类型uuid: 单词（不能含空格）; name: 单词（不能含空格）;

/contribution account migrate <sourceUuid> <targetUuid> confirm

功能
把源唯一标识符的账户及关联数据迁移到目标唯一标识符。
权限
主服务器控制台管理员；无在线玩家
示例
/contribution account migrate <源唯一标识符> <目标唯一标识符> confirm
参数与限制
执行前备份；目标须满足空账户/身份约束，不是合并余额。
原版参数类型sourceUuid: 单词（不能含空格）; targetUuid: 单词（不能含空格）;

/contribution add <selected> <amount> <reason> <affectTotalIncome>

功能
增加贡献值，可指定是否增加历史总收入。
权限
管理员
示例
/contribution add CaoZei 100 "活动奖励" true
参数与限制
金额≥1 且≤2147483647；原因及备注最多 64 字符；目标支持名称、唯一标识符或玩家选择器。
原版参数类型selected: 玩家选择器; amount: longArg(1, 2147483647); reason: 字符串（空格需引号）; affectTotalIncome: true|false;
