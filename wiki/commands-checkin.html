签到命令

签到命令用于查询每日状态、浏览和领取活动奖励，以及由管理员创建活动。

  1. 使用
  2. 示例
  3. 本模块命令路径

使用

签到命令分为玩家侧与管理侧：玩家查看并领取活动奖励，管理员在主服务器定义活动。

  • 每日在线签到没有手动领取命令：当天累计在线满 600 秒后自动发放。
  • /contribution checkin events 列出当前可领取的活动；claim <活动ID> 每名玩家每个活动只能领取一次。
  • 活动日期为 YYYY-MM-DD 的现实日期，采用配置时区，起止两日均包含。
  • 活动创建只允许在主服务器执行；当前版本只提供创建，不提供编辑已发布的活动。
  • create-extension 需要由其他模组先注册奖励提供者，否则活动无法创建。

示例

/contribution checkin
/contribution checkin events
/contribution checkin claim festival

本模块命令路径

共 6 条命令路径，权限、示例与参数要求列在各条目中。

/contribution checkin

功能
查看在线签到状态、活动；管理活动创建与领取。
权限
查看/领取：玩家；event 子命令：管理员且主服
示例
/contribution checkin claim festival
参数与限制
create 日期为 YYYY-MM-DD，首尾日期均包含；每日签到自动发放。create-extension 需要已注册提供者。

/contribution checkin claim <eventId>

功能
领取指定活动奖励，每名玩家每活动最多一次。
权限
玩家
示例
/contribution checkin claim festival
参数与限制
只可在活动日期内领取，日期按配置时区。
原版参数类型eventId: 单词（不能含空格）;

/contribution checkin event create <id> <title> <start> <end> <contribution>

功能
创建仅贡献值奖励的活动签到。
权限
管理员；只允许主服务器创建
示例
/contribution checkin event create festival "庆典" 2026-10-01 2026-10-07 100
参数与限制
日期首尾包含；金额可为 0；标识符不可重复。
原版参数类型id: 单词（不能含空格）; title: 字符串（空格需引号）; start: 单词（不能含空格）; end: 单词（不能含空格）; contribution: integer(0);

/contribution checkin event create <id> <title> <start> <end> <contribution> <item> <count>

功能
创建贡献值与物品混合奖励的活动。
权限
管理员；只允许主服务器创建
示例
/contribution checkin event create festival "庆典" 2026-10-01 2026-10-07 100 minecraft:diamond 2
参数与限制
此 item 是普通物品标识符，不是商店的组件物品参数；数量 1—2304。
原版参数类型id: 单词（不能含空格）; title: 字符串（空格需引号）; start: 单词（不能含空格）; end: 单词（不能含空格）; contribution: integer(0); item: 单词（不能含空格）; count: integer(1, 2304);

/contribution checkin event create-extension <id> <title> <start> <end> <provider> <data>

功能
使用已注册扩展奖励提供者创建签到活动。
权限
管理员；只允许主服务器创建
示例
/contribution checkin event create-extension festival "庆典" 2026-10-01 2026-10-07 example:reward "{}"
参数与限制
提供者须由其他模组注册；处理器只用领取事务的数据库连接，不能任意执行命令。
原版参数类型id: 单词（不能含空格）; title: 字符串（空格需引号）; start: 单词（不能含空格）; end: 单词（不能含空格）; provider: 单词（不能含空格）; data: 字符串（空格需引号）;

/contribution checkin events

功能
列出可领取的活动签到。
权限
玩家
示例
/contribution checkin events
参数与限制
与每日在线签到独立。
