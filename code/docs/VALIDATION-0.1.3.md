## 分发 JAR 服务端验证

最终 JAR 使用 `verifyPackagedServer --offline` 加载为 `contribution 0.1.3`，在已有测试世界启动到 `Done`。独立测试 MySQL 从 V14 升级至 V17；再次启动确认迁移校验与目录初始化完成，无需重复迁移。

实际控制台执行 `shop put_on minecraft:diamond "Test Namespace" 4 100 "namespace-description"`，成功分配商品 #5。随后执行 `shop modify 5 - - 75 updated-description` 和 `shop take_off 5`，数据库核实售价 75、描述更新、下架状态、版本为 2。

执行完整表单命令创建商品 #6，再通过 `shop admin save` 将物品改为胡萝卜、每份 8、售价 50、排序 1、描述更新并下架；数据库字段均符合提交结果。服务端正常 `stop` 退出。测试实例已正常关闭，临时 Q: 路径映射已解除。

## 边界与未验收项目

尚未在真人客户端逐项点击商品卡片或以截图验收各 GUI 缩放比例。本版改用注册的 `AbstractWidget.onClick` 商品控件，并完成构建，但这不等于已完成真实客户端鼠标与视觉验收；原版表单也仅验证编解码与实际对应命令，未在原版客户端逐按钮操作。

未在真实多服部署进行联调或测量 MSPT。商品 SQL 使用既有有界线程池，客户端筛选排序只在输入变化时计算，绘制不访问数据库。MySQL 测试服务仅监听本机 23306；中文路径启动截断通过临时盘符映射解决，没有修改操作系统或安装全局服务。启动时原版系统信息组件曾报告 Windows 性能计数器警告，但未阻止服务端启动与测试。

商品目录导入后不再随 `rewards.shopOffers` 修改，需使用管理界面或命令。群组服升级时须全部更新同版，由主服迁移；停服并备份数据库后再升级。
