# 贡献值模组设计

## 项目概述

本项目是面向 Minecraft Java Edition 26.3、基于 Fabric 的服务端代币模组。所有服务端命令均以 `/contribution` 开头。

当前 `0.0.2` JAR 已实现 Basic 功能、股票系统及公共运行机制。签到、商城仍是待实现的拓展设计；自定义行业也尚未实现。

模组需要满足以下基础要求：

- 原版客户端可以直接进入服务器。
- 图形界面属于 Basic，使用 26.3 原生 Dialog，原版客户端也能打开全部基础页面。
- 单人游戏和单服默认在世界文件夹中自动创建嵌入式数据库，无需安装数据库服务；群组服显式使用共享 MySQL 数据库，以配置指定统计服务器。
- 单服的账户、流水、建设度和统计恢复日志集中在世界目录的 `contribution/` 中；群组服的权威数据在共享 MySQL 中，本地目录只存恢复日志。运行配置另存于 `config/contribution/server.json`。
- 仅交付一份通用 JAR，经济和统计在逻辑服务端运行，客户端不必安装。

## 功能划分

### 基本功能

- [贡献值账户](basic/contribution-account.md)：账户、余额、流水、查询、余额变更 API、管理员命令、权限和反馈文本。
- [服务器建设度统计](basic/server-development.md)：行业建设度、每日统计、总建设度、繁荣度、来源规则和持久化。当前实现阶段只覆盖九个内置行业；自定义行业保留为后续设计。
- [玩家统计数据](basic/player-statistics.md)：玩家总放置、总挖掘以及各行业累计建设度。
- [图形界面](basic/graphical-interface.md)：账户、流水、统计、行业总览及管理员操作，原版客户端可用。

### 拓展功能

- [股票系统](extensions/stock.md)：已实现依赖行业繁荣度的股价、上市、退市、交易和原版客户端曲线界面。
- [每日签到](extensions/check-in.md)：现实自然日签到及奖励接口。
- [系统商城](extensions/marketplace.md)：商店、回收、拍卖和抽奖的待设计范围。

### 公共技术设计

- [运行时与性能架构](infrastructure/runtime-architecture.md)：依赖选择、线程模型、连接池、迁移、配置、日志、缓存和兼容策略。
- [其他模组调用 API](../code/docs/API.md)：面向其他 Fabric 模组作者的贡献值 API 调用说明。

## 系统关系

贡献值账户、服务器建设度统计和玩家统计数据是模组的基本功能。玩家统计数据与服务器建设度统计共享已经确认成功的玩家操作事件和建设度去重结果。繁荣度是服务器建设度统计内部根据行业建设度计算的指标；股票系统依赖繁荣度，但服务器建设度统计不依赖股票系统。股票买卖与账户更新在同一数据库事务中完成，不经异步公共 API 拆成两笔；签到、商城等未来功能可使用统一 API。

跨服事务、幂等和全服定时任务属于各功能共同遵守的技术约束，不单独构成玩家功能。
