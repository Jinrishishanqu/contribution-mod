## 项目概述

0.1.13按四份人工定义实施行业标签及事件计数，合成每64个实际产物计一次，交通每10格计一次，默认贡献权重1/250。对象标签已同步；事件分批实施状态与覆盖边界见[行业定义实施进度](basic/industry-definition-rollout.md)。

本项目是面向 Minecraft Java Edition 26.3、基于 Fabric 的代币模组。贡献值与建设度命令以 `/contribution` 开头，股票命令独立以 `/stock` 开头。

当前 `0.1.12` 实现 Basic、股票、建设度奖励、每日/活动签到、可管理的系统商店，以及内置合成、添翼/强化/主题盔甲、变形帽子、公示喇叭、哑炮、头颅采集与纯 JSON 进度。股票观察时钟与结算独立调度，旧日统计按日期关账与追赶；股票客户端屏幕不暂停单人世界，刷新与推送有序接收。管理员可用 `/contribution diagnose` 检查时钟、规则、缓冲和核算，触发安全恢复并接收聊天报告。回收、拍卖、抽奖和自定义行业尚未实现。

模组需要满足以下基础要求：

贡献首页新增公开排行榜，默认“富豪榜”；另有历史总收入、总建设度及九行业建设度排行，两套界面均可用。

- 原版客户端可以直接进入服务器。
- 原版客户端通过 26.3 原生 Dialog 打开全部贡献值、股票和商店基础页面；安装同一 JAR 的客户端分别使用专用界面。三个命令的 `ui_vanilla` 子命令可在已安装客户端模组时强制测试原版界面。
- 单人游戏和单服默认在世界文件夹中自动创建嵌入式数据库，无需安装数据库服务；群组服显式使用共享 MySQL 数据库，以配置指定统计服务器。
- 单服的账户、流水、建设度和统计恢复日志集中在世界目录的 `contribution/` 中；群组服的权威数据在共享 MySQL 中，本地目录只存恢复日志。运行配置另存于 `config/contribution/server.json`。
- 仅交付一份通用 JAR，经济和统计在逻辑服务端运行；客户端安装为可选项。

## 功能划分

### 基本功能

- [贡献值账户](basic/contribution-account.md)：账户、余额、流水、查询、余额变更 API、管理员命令、权限和反馈文本。
- [服务器建设度统计](basic/server-development.md)：行业建设度、每日统计、总建设度、繁荣度、来源规则和持久化。当前实现阶段只覆盖九个内置行业；自定义行业保留为后续设计。
- [玩家统计数据](basic/player-statistics.md)：玩家总放置、总挖掘以及各行业累计建设度。
- [贡献点边际计价规格（放置与挖掘）](basic/contribution-pricing.md)：**设计规格，未实现**。只重设贡献点价格，把放置/挖掘改为按当日建设度分段递减单价，使批量建造收益不超过手搭玩家的 1.2 倍；建设度、繁荣度与股票不受影响。价格对比见[前后对比（注释版）](basic/contribution-pricing-comparison.md)。
- [图形界面](basic/graphical-interface.md)：账户、流水、统计、行业总览及管理员操作，原版客户端可用。

### 拓展功能

- [一次性武器皮肤](extensions/weapon-skins.md)：六类原初烟火之星右键定型为对应金质武器；按item_name选择外观，原版客户端Dialog与默认商店支持。

- [股票系统](extensions/stock.md)：已实现依赖行业繁荣度的股价、上市、退市与交易；可选客户端提供真正的像素曲线，原版客户端保留文字界面。
- [离线 Wiki](../wiki/index.html)与[指令 XLSX](../documentation/commands.xlsx)：从实际命令树导出贡献、签到、股票、商店的全部玩家及管理员用法。
- [每日与活动签到](extensions/check-in.md)：现实日在线时长、周期奖励和活动领取。
- [系统商城](extensions/marketplace.md)：已实现商店；回收、拍卖和抽奖留待后续。

## 系统关系

贡献值账户、服务器建设度统计和玩家统计数据是模组的基本功能。玩家统计数据与服务器建设度统计共享已经确认成功的玩家操作事件和建设度去重结果。繁荣度是服务器建设度统计内部根据行业建设度计算的指标；股票系统依赖繁荣度，但服务器建设度统计不依赖股票系统。股票买卖、签到、建设度奖励和商店扣款都与账户、流水及各自业务记录在同一数据库事务中完成。

跨服事务、幂等和全服定时任务属于各功能共同遵守的技术约束，不单独构成玩家功能。
