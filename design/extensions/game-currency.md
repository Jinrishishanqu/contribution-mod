# 游戏币系统

> 当前实现基线：0.2.6。完整指令与权限以[离线 Wiki](../../documentation/wiki.html)和[指令表](../../documentation/commands.xlsx)为准；功能变更须同步代码、本文及统一文档源。

游戏币（GC）是股票等投机玩法专属的孤立货币，用于把零和玩法与贡献经济分开。贡献值代表玩家对服务器的贡献；如果赌博、零和玩法直接消耗与产生贡献值，会使其快速通胀并失去贡献的含义。游戏币以贡献值兑换获得，是一套购买力有限但确实具备购买力的低价值货币系统。

游戏币通过购买力锚定价值，同时与贡献点分账存储。由于用途限定在玩法内容内，持有大量游戏币也不会对贡献经济形成垄断；它只是一套相对孤立的低价值货币，不会干扰贡献经济。

## 与贡献点的边界

- 兑换游戏币时，所用贡献值**直接销毁**，不再进入任何账户；兑换不是形态转换，而是贡献点的通缩口。
- 兑换不会增加贡献点总量，也不会产生新的贡献值；贡献账户只减不增。
- 游戏币与贡献点分别在两套表和两套流水中记账，互不混用。
- 股票买卖、退市返还全部以游戏币结算，不再改动贡献账户余额或历史总收入。

## 兑换

| 项目 | 说明 |
| --- | --- |
| 兑换命令 | `/gc exchange <贡献值>`；结果不确定时用 `/gc retry <请求ID> <贡献值>` |
| 兑换比例 | 由服务器配置 `gameCurrency.exchangeRateMilli` 调整；`950` 表示 1 贡献值 = 0.95 游戏币 |
| 数量范围 | 1—1000000 贡献值 |
| 记账 | 单事务内扣除贡献值并写入游戏币；幂等 ID 跨两套流水检测，避免重复兑换 |

令 $x$ 为兑换的贡献值数量、$e$ 为百万分之一比例（milli-GC 每贡献值），则发放的游戏币（milli 单位）为

$$
g = x \times e
$$

兑换流程：

1. 校验请求幂等 ID 未在贡献流水或游戏币流水中使用，且贡献值余额充足。
2. 在同一事务内扣减贡献账户余额，写入一条 `type=EXCHANGE`、`source=contribution:game_currency`、`income_delta=0` 的贡献流水，记录被销毁的贡献值。
3. 在同一事务内向游戏币钱包入账 $g$（milli 单位），写入游戏币流水。
4. 任一步失败整体回滚；已完成请求按原幂等 ID 重放，不会二次销毁贡献值。

## 货币表示与显示

- 游戏币以千分之一为单位存储为 `BIGINT`，记为 milli-GC，保证可调比例下的换算精确。
- 显示时最少零位、最多三位小数并去掉末尾零：`95000 → 95`、`950 → 0.95`。
- 手续费与成交额全部以 milli-GC 整数运算，避免浮点误差。

## 手续费

股票买卖沿用原有 2% 手续费，作为可复用的税项，买卖两侧都收取：

$$
\text{gross} = Q \times P \times 1000
$$

$$
\text{fee} = \left\lfloor \frac{\text{gross} \times 2 + 50}{100} \right\rfloor
$$

其中 $Q$ 为数量、$P$ 为当日股价、`gross` 为 milli-GC 成交额；买入应付 `gross + fee`，卖出到账 `gross - fee`。

## 数据存储

V23 迁移新增两张表，与贡献账户同在单服世界数据库或群组服共享 MySQL：

| 表 | 用途 |
| --- | --- |
| `game_currency_account` | 玩家游戏币钱包；`balance_milli` 为 milli-GC，名称归一化唯一；迁移时为已有贡献账户播种零余额钱包 |
| `game_currency_transaction` | 游戏币流水；字段对齐贡献流水，金额与变动前后余额均以 milli-GC 存储 |

V23 同时改造股票结算：

- `stock_trade` 增加 `currency VARCHAR(16) NOT NULL DEFAULT 'CP'`，`account_delta` 改为 `BIGINT`。历史行保持原整数贡献值并标记 `CP`，读取成本基准时按 `×1000` 换算；新行以 milli-GC 写入并标记 `GC`。
- `stock_refund.amount` 与 `claimed` 按 `×1000` 迁移，把历史退市返还原的整数贡献值换算为 milli-GC。

存量迁移：既有股票持仓与退市返还按 1 贡献值 = 1 游戏币转换为游戏币；历史流水保留原币种标记，不重算已完成交易。

## 命令

```text
/gc
/gc balance
/gc exchange <贡献值>
/gc retry <请求ID> <贡献值>
```

`/gc` 与 `/gc balance` 显示余额、当前兑换比例与最近流水。`/gc` 根命令独立于 `/contribution` 与 `/stock`。完整命令见[命令速查](../../code/docs/COMMANDS.md)。
