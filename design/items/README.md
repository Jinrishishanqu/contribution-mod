# Datapack 内容索引

本目录记录 `datapack/` 的静态分析结果。分析对象同时包含服务端数据包（`data/`）和客户端资源包（`assets/`），不等同于当前 Fabric 模组已经迁移或正式支持的功能。

**0.1.4 已迁入的六类功能及最终规则见 [内置功能实现](builtin-content.md)**。以下原型文档保留历史记录，配方格式、装备数据保留和进度谓词以实现页为准。

## 总体规模

| 类型 | 数量 | 主要用途 |
| --- | ---: | --- |
| JSON | 600 | 进度、配方、谓词、战利品表、附魔、模型与装备渲染 |
| `mcfunction` | 71 | 初始化、循环统计、属性、技能、特殊物品与成就辅助逻辑 |
| PNG | 218 | 武器、盔甲、翅膀、玩偶等纹理 |
| `mcmeta` | 7 | 包元数据与动画纹理元数据 |
| 禁用 JSON | 1 | 已停用的逐刻玩家入口 |

数据包声明 `pack_format: 71`，版本文案为 `v0.0.1`。主要命名空间是 `csumc` 与 `csumc_adv`；另有 `minecraft` 命名空间文件直接覆盖原版内容。

## 实现关系

核心交互普遍使用“进度触发器 → 奖励函数 → 撤销辅助进度”的循环结构；物品身份依赖 `item_name`、`item_model` 或 `custom_data` 组件。复杂的动态数值通过计分板暂存，再写入命令存储 `storage csumc`，最后用函数宏生成组件或属性命令。

`csumc_adv` 是展示型成就树；其中不可直接由原版触发器表达的条件，会先由隐藏进度触发辅助函数，再由函数授予或撤销可见成就。

## 阅读约定

- “已接通”表示能从 `load`、进度奖励、函数调用、配方或原版覆盖中找到完整入口。
- “资源存在”只说明文件存在，不代表玩家能在正常流程中取得或使用。
- “覆盖原版”表示文件位于 `data/minecraft` 或 `assets/minecraft`，会与其他包的同路径资源产生覆盖顺序冲突。
