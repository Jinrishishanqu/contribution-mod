# 0.1.6 内置合成、装备与进度

本页记录已实现的最终规则。其他 items 文档仍是旧原型盘点，不表示所有原型均已迁入。

## 加载方式与兼容

所有玩法定义位于模组 JAR 的 `data/contribution/`，作为 Fabric 的默认模组数据包在启动/进入存档时加载；不需要安装独立数据包或执行 `/reload`。没有新增物品注册项，也没有 mcfunction、load/tick 函数、循环实体扫描或经济扣款。数据包使用 26.3 原生配方、组件与进度。 鞘翅复制例外使用仅在合成时执行的配方余物处理，不增加 tick 扫描：原版禁止有耐久且可堆叠，也拒绝输出超出最大堆叠数的结果。

所有自定义装备仍是原版物品 ID，原版客户端可进入和使用。外观定义位于 `assets/contribution/`，不覆盖 minecraft 的模型、atlas 或配方。安装同一模组的客户端自动加载外观；**未安装客户端模组的玩家要显示主题贴图和添翼外观，必须另外收到服务器资源包**。服务端不会通过 JAR 自动把资源发送给原版客户端。 另补充十八种原版图案缺失的 minecraft:textures/trims/entity/wings 透明纹理，保留胸甲纹饰、不在翅膀叠加纹饰，修复紫黑贴图；不覆盖 atlas。

构建生成 `code/build/libs/CSU-YSU-items-0.1.6-resource-pack.zip`，同时内嵌于 JAR。启动时自动导出到 `<世界>/contribution/resource-packs/CSU-YSU-items-<模组版本>.zip`。已有同版本文件不覆盖；更新版本会生成新文件。本模组不擅自开启 HTTP 端口、修改防火墙或覆盖现有服务器资源包。由管理员将 ZIP 放到已有资源包分发地址，并按原版 `server.properties` 的 `resource-pack` 和 `resource-pack-sha1` 设置发送；若已有其他资源包，应合并后分发。`require-resource-pack=false` 可允许玩家拒绝外观包仍进入。 run-gradle.ps1 build 成功后自动备份并替换两处 JAR 及指定客户端 resourcepacks 中本模组的旧 ZIP；不修改其他资源包或 options.txt，客户端须选择新版本资源包。

## 胸甲添翼：七个锻造配方

配方 `contribution:items/wings/<材质>`：下界合金升级锻造模板 + 本材质胸甲 + 鞘翅。材质是皮革、锁链、铜、铁、金、钻石、下界合金。消耗每格一个输入，保留胸甲的物品 ID，设置 glider、最大耐久 592、物品实体抗火与该材质的胸甲+翅膀装备层。 结果设置 contribution:winged/<材质> 物品模型，并写入灰色非斜体“添翼” lore；该 lore 替换基底旧 lore。皮革支持染色，七种物品模型支持十一种纹饰材料；铜图标为原版胸甲叠加翼装图层，其他金属复用原型添翼图标。主题添翼配方也有“添翼” lore。

使用原版 smithing_transform 复制基底组件，再覆盖上述必要字段；保留自定义名称、附魔、损耗耐久、纹饰、染色和已有强化属性。抗火指掉落物抗火，不是穿戴者免疫火焰。没有覆盖原版钻石→下界合金配方，故原版升级可以保留已有 glider，不会主动抹除翼装。

## 下界合金强度强化：61 个锻造配方

配方 `contribution:items/reinforcement/<物品>`：下界合金升级锻造模板 + 原装备 + 同部件下界合金装备。输出仍是原装备 ID，并固定写入强化名称、耐久、物品抗火和最终属性，不叠加已有属性。

| 范围 | 最大耐久 | 固定属性 |
| --- | --- | --- |
| 皮革/锁链/铜/铁/金/钻石头盔，以及海龟壳 | 407 | 护甲 3、韧性 3、击退抗性 0.1 |
| 上述六材质胸甲 | 592 | 护甲 8、韧性 3、击退抗性 0.1 |
| 上述六材质护腿 | 555 | 护甲 6、韧性 3、击退抗性 0.1 |
| 上述六材质靴子 | 481 | 护甲 3、韧性 3、击退抗性 0.1 |
| 木/石/铜/铁/金/钻石剑、镐、斧、锹、锄 | 2031 | 主手伤害 modifier 分别 7/5/9/5.5/0，速度 modifier 分别 -2.4/-2.8/-3/-3/0 |
| 木/石/铜/铁/金/钻石矛 | 2031 | 伤害 modifier 4、速度 modifier -3.13043475151062，刺击动画与 kinetic_weapon 采用原版下界合金矛完整参数 |

工具面板总伤害和速度还包含玩家基础值。工具的挖掘等级、速度、修复材料仍由原物品 ID 决定，不将金工具暗中变成下界合金工具。修正了原型钻石锄缺少最终属性定义的问题。添翼后再强化仍保留 glider；重复强化不会叠加数值。不迁入不死图腾强化。 攻击属性改用 minecraft:base_attack_damage/base_attack_speed，使原版显示绿色无正负号的总值；新增材质也纳入强化进度。已有物品不会自动被改写，可再次锻造应用新组件；没有后台扫描、旧物品批量迁移或无消耗更新命令。

## 三套主题盔甲：15 个配方

| 主题 | 附加材料 | 部件 |
| --- | --- | --- |
| Mark 6（ID mark_6） | 铁锭 | 头盔、胸甲、护腿、靴子、翼装胸甲 |
| 纳米（ID nano） | 恶魂之泪 | 同上 |
| 量子（ID quantum） | 末影珍珠 | 同上 |

四件普通部件使用工作台 `crafting_transmute`：下界合金部件 + 一份主题材料，不限摆放。它保留原装备组件，避免原型 shapeless 清空附魔、修复惩罚、损耗耐久。输出改变主题名称、史诗稀有度、物品模型和装备外观，不额外增加战斗数值。

翼装胸甲使用锻造台：**主题材料放模板槽、下界合金胸甲放基底槽、鞘翅放附加槽**；同时得到主题胸甲和滑翔组件，保留基底其他数据。这取代原型的三材料 shapeless，避免丢失装备数据。主题翼装使用独立的外观资源；普通添翼配方会把胸甲外观换成对应基础材质。将已经添翼的胸甲再用普通主题配方换皮肤，滑翔能力仍保留，但外观改为无翅膀的主题装甲；想让翅膀也可见应使用主题翼装锻造配方。

复用用户提供的 22 张主题 PNG，另将三张成人装甲纹理复用到婴儿装备层，共 25 张打包纹理，路径重新标准化到 contribution；不导入旧武器名称路由、纹饰 atlas、语言覆盖。纳米/量子设计来源为原型注明的 Industrial Craft 2；本项目不宣称取得第三方素材的独占权。 0.1.6 另复用六张添翼图层 PNG、十八张透明翅膀纹饰 PNG，并复制原版青色混凝土粉末为独立 GUI 背景，共 50 张打包 PNG。新树背景引用 contribution:gui/advancements/backgrounds/cyan_concrete_powder，避免旧格式 textures 前缀被重复展开。

## 37 个可见进度与根节点

新树根为 `contribution:items/root`，“更多乐趣”。重接缺失父节点，不迁入 impossible/函数/全局计分板成就。

- 繁殖：小牛、蓝色美西螈。
- 战斗：监守者近战击杀、单击造成至少 36.5 伤害、驯服马击杀、双剑滑翔击杀、箭命中未着地实体、箭对末影龙造成至少 200 伤害。
- 危险：在水中受熔岩伤害、撞墙至少 20 伤害、深处虚空伤害、疣猪兽击败、细雪附近雷击、监守者音爆击败。
- 探索：世界边境、村庄、使用望远镜。
- 获得物品：用坏下界合金镐、烤马铃薯、火把、灵魂火把、佩戴玩家头。
- 操作：远离世界中心放置方块、点亮指定文字告示牌、放比较器、相邻黏液块与珊瑚扇的 TNT 放置。
- 羊系列：六种指定颜色、jeb_ 命名、十六种颜色交互加 jeb_ 命名的羊村。
- 升级：胸甲添翼、工具强化、盔甲强化。

每项只依靠自己的 advancement JSON，无额外函数或自定义标签。26.3 的触发器实体字段使用显式 entity_properties，实体子谓词采用命名空间键；羊色/美西螈变种匹配原生组件。伤害类型直接引用具体 damage_type；位置条件是显式 all_of/any_of，不使用旧隐式数组。颜色羊进度描述按“对已有该颜色羊使用指定染料”理解，并不把交互前颜色当成交互后的染色结果。强度升级进度精确检查该装备的最终强化属性，避免抗火翼装误判。

未迁入赛级马、猪灵繁殖、累计命中/树苗、治愈者死亡、对牛弹琴等需要函数计数或二次实体搜索的原型；帽子、不死强化、精灵球/哑炮/中指进度也不随本次引入无获取途径的条目。

## 26.3 调研依据与验证

本机 26.3 `version.json`：数据包 121.0、资源包 97.1、Java 25。原型 pack_format 71 不能作为目标规则。

先查阅 [Wiki 锻造](https://zh.minecraft.wiki/w/锻造)、[Wiki 数据组件](https://zh.minecraft.wiki/w/数据组件)的可访问检索内容；Wiki 正文 robots 限制无法进一步读取。版本变化和谓词语法以 [26.3 官方发布说明](https://www.minecraft.net/en-us/article/minecraft-java-edition-26-3)及本机 26.3 原版资源/Codec 为准。

验证任务 `verifyItemContent` 逐一通过原版 Recipe/Advancement/Equipment Codec；实际装配检查名称、损耗耐久、附魔、纹饰、glider 保留；资源包元数据和 PNG 有效性检查也进入 build。服务端与视觉验证边界见 `code/docs/VALIDATION-0.1.6.md`。 新增检查覆盖所有材质强化装配、原版攻击属性 ID 与数值、矛蓄力参数、添翼模型/lore、全部原版翅膀纹饰纹理以及背景实际路径。
