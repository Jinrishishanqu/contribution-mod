# 图形界面

贡献值 Basic 图形界面按客户端能力选择：安装本模组的客户端使用可选的像素对齐页面；未安装模组的原版客户端继续使用 Minecraft 26.3 原生 Dialog。服务端始终负责查询和权限验证，原版客户端无需安装模组。股票和商店同样各有可选客户端页面及原版 Dialog 后备界面。

输入 `/contribution` 或 `/contribution ui` 打开首页。安装客户端模组时，账户与统计、流水、行业、签到、管理员查询、账户列表和查询结果都使用同一套客户端页面，不在跳转时自动切回 Dialog。`/contribution ui_vanilla` 可强制打开原版 Dialog，并在本次页面导航中维持原版模式；重新输入 `/contribution` 恢复专用客户端界面。文字命令与聊天分页保留，控制台继续使用文字命令。

## 页面

| 页面 | 内容与交互 |
| --- | --- |
| 首页 | 我的账户与统计、我的流水、行业建设度、每日签到与活动；管理员额外看到“管理员功能”入口。股票和商店分别由 `/stock`、`/shop` 打开。首页不放输入框，避免高界面缩放时页面贴近屏幕底部 |
| 签到 | 今日在线秒数与自动签到状态、活动期限和奖励；可点击领取活动奖励 |
| 管理员功能 | 账户列表、全服流水，以及通过名称或 UUID 查询玩家账户与统计；返回首页 |
| 账户与统计 | 合并余额、历史总收入、UUID、原始放置、挖掘和个人总建设度；九行业个人建设度每行三个，共三行；支持刷新、查看流水、返回上一页和首页。旧 ui stats 链接打开同一合并页 |
| 行业总览 | 首行是行业、当日、总建设度、繁荣度、核算日的标题；九行业各占一行，内容仅显示对应数值；繁荣度显示时四舍五入保留两位小数，数据库精度不变，支持刷新 |
| 账户列表 | 管理员按名称分页，图形界面每页 8 个账户，可点击进入详情 |
| 流水 | 图形界面每页 8 条；首行显示时间、玩家、变动、余额、类型和原因的列标题，每笔流水只占一行。数据库仍以 UTC 保存时间，界面按配置的 `rewards.timeZone` 显示为 `MM-dd HH:mm`，默认 `Asia/Shanghai`；支持筛选、刷新、上一页、下一页、返回第一页，刷新保留当前筛选和翻页位置 |
| 管理员变动 | 两套界面均不提供账户变动输入、预览或确认。仅使用 /contribution add/remove 命令；旧 ui prepare/confirm 请求拒绝执行 |

安装模组的客户端采用服务端下发的结构化行数据和固定像素列，行业建设度、统计与流水表格的标题和数值可精确对齐，流水原因过长时在列内截断。原版 Dialog 无法保证空格排版的像素精度，后备页用内置等宽字体与固定显示列宽提供紧凑的单行记录。客户端页可点选“全部”“股票买入”“股票卖出”等常用筛选；原版流水页保留“全部流水”“股票买入”“股票卖出”“管理员调整”“退市返还”按钮。其他筛选仍可使用 `type/source/server/from/to` 的 `名称=值` 高级格式，与文字命令共享解析及权限。筛选日期仍按 UTC 日界线计算并包含结束日期；界面注明该区别。普通玩家只能查询本人最近 90 天；管理员可查历史归档，单次最多 365 天。查询其他玩家使用名称或 UUID，目标选择器仍由文字命令提供。

数据从当前数据库异步读取，不阻塞服务器线程；界面反映已提交的数据，统计正常有约 5 秒批量提交延迟。数据库不可用时显示错误页，按本地文件库或共享 MySQL 给出不同排查提示，不显示缓存余额冒充实时余额。单人和单服默认自动创建世界内嵌入式数据库；群组服连接共享 MySQL。客户端专用页的 Esc 先关闭当前画面并请求返回上一页，即使服务端暂时不响应也能退出；首页 Esc 直接退出。原版子页面底部提供“返回上一页”，Esc 使用原生 Dialog 的取消动作执行相同命令。每名玩家最多记住最近 20 个页面跳转；主动返回首页会清空返回记录。纯页面导航不经过交易请求限流；异步查询返回时若玩家已经切到其他页面，则丢弃旧查询结果，避免覆盖新画面。

客户端页在存在输入框时为标签、输入框与表格标题分别预留垂直空间；操作按钮按网格居中排列，空白的管理员页面不显示“暂无记录”。

## 权限与提交

管理员权限使用原版管理员级别（通常 OP 等级 2）。服务端重新校验每个请求，隐藏按钮不是权限控制。未授权玩家手动输入内部页面命令，也不能查询他人或修改余额。

管理员余额调整仅通过文字命令执行，数量、布尔值、原因和备注遵循账户设计中的限制；图形页面不能绕过这些校验。旧图形预览令牌流程已移除。

交易与数据变更命令仍使用请求限流：每位玩家最多突发 8 次，正常每 10 tick 恢复 1 次，全服每 tick 最多接受 40 次。纯界面导航不占用该配额。

股票市场从贡献值首页分离，使用 `/stock` 打开；其曲线和买卖界面详见[股票系统](../extensions/stock.md)。商店独立使用 `/shop`，可选客户端提供商品图标与搜索界面，原版客户端使用原生 Dialog。签到仍从贡献值首页进入。

## 0.1.5 导航与布局

账户列表与活动行使用注册的 AbstractWidget 接收点击，支持悬停边框、手形光标和键盘聚焦；不依赖屏幕手写坐标判断。滚动时复用当前可见行控件。客户端所有子页自动补充返回入口；账户列表增加上一页、第一页和返回管理。流水按顺序翻页时可返回上一页，返回栈恢复该页的游标和筛选。内容区按实际按钮行数计算，避免第三行按钮覆盖表格；窄屏流水按比例分配列宽，行业总览五列等宽。

合并账户页的账户摘要、原始操作统计和行业建设度分区绘制，超出高度时滚轮滚动并显示只读滚动条。客户端贡献页面不暂停单人世界；首页关闭会使服务器待完成的查询失效，防止迟到结果再次打开界面。
