# 图形界面

> 当前实现基线：0.1.8。完整指令与权限以[离线 Wiki](../../documentation/wiki.html)和[指令表](../../documentation/commands.xlsx)为准；功能变更须同步代码、本文及统一文档源。

贡献值 Basic 图形界面按客户端能力选择：安装本模组的客户端使用可选的像素对齐页面；未安装模组的原版客户端继续使用 Minecraft 26.3 原生 Dialog。服务端始终负责查询和权限验证，原版客户端无需安装模组。股票和商店同样各有可选客户端页面及原版 Dialog 后备界面。

输入 `/contribution` 或 `/contribution ui` 打开首页。安装客户端模组时，账户与统计、流水、行业、签到、管理员查询、账户列表和查询结果都使用同一套客户端页面，不在跳转时自动切回 Dialog。`/contribution ui_vanilla` 可强制打开原版 Dialog，并在本次页面导航中维持原版模式；重新输入 `/contribution` 恢复专用客户端界面。文字命令与聊天分页保留，控制台继续使用文字命令。

## 页面

### 排行榜

首页“排行榜”按钮与 `/contribution leaderboard` 默认打开富豪榜，按当前贡献余额降序。可切换历史贡献（历史总收入）、总建设度（九行业之和）与九个行业的建设度榜。客户端和原版Dialog提供相同功能，任何玩家可查公开名次、玩家名及数值，不展示UUID或他人私有账户详情。

每榜展示前100名，每页8名；同值按UUID稳定排序，名次为顺序序号。建设度只计入已提交数据库的正值，零建设度与bot_账户不参榜；贡献榜包含零余额/零收入账户。服务端每类别缓存15秒并共享在途查询，刷新不会绕过缓存。数据库后台排序与汇总，单页仅发送8行。

富豪榜Esc返回首页；历史贡献/总建设度Esc返回默认富豪榜；行业榜Esc返回行业列表，行业列表再返回默认富豪榜。翻页不改变Esc父页面，客户端在同类视图中更新信息块。所有榜页提供刷新、榜类切换和显式关闭入口。

客户端排行榜操作区固定两行：第一行从左到右为“富豪榜、历史贡献、总建设度、各行业榜”，四列等宽；第二行为“上一页、刷新、下一页”，三列等宽，刷新居中。第一页/末页仍保留禁用的翻页按钮，不改变布局；底部独立保留“返回上级、首页、关闭”。其他客户端页面保留原有四列操作网格，原版Dialog功能不变。

| 页面 | 内容与交互 |
| --- | --- |
| 首页 | 我的账户与统计、我的流水、行业建设度、每日签到与活动；管理员额外看到“管理员功能”入口。股票和商店分别由 `/stock`、`/shop` 打开。首页不放输入框，避免高界面缩放时页面贴近屏幕底部 |
| 签到 | 今日在线秒数与自动签到状态、活动期限和奖励；可点击领取活动奖励 |
| 管理员功能 | 输入框下直接显示可点击的账户列表；客户端输入后延迟 450 毫秒按名称前缀或完整 UUID 搜索，原版 Dialog 提供筛选按钮；全服流水和查询玩家保留 |
| 账户与统计 | 合并余额、历史总收入、UUID、原始放置、挖掘和个人总建设度；九行业个人建设度每行三个，共三行；支持刷新、查看流水、返回上级和首页。旧 ui stats 链接打开同一合并页 |
| 行业总览 | 首行是行业、当日、总建设度、繁荣度、核算日的标题；九行业各占一行，内容仅显示对应数值；繁荣度显示时四舍五入保留两位小数，数据库精度不变，支持刷新 |
| 账户列表 | 管理员按名称分页，图形界面每页 8 个账户，可点击进入详情 |
| 流水 | 图形界面每页 8 条；首行显示时间、玩家、变动、余额、类型和原因的列标题，每笔流水只占一行。数据库仍以 UTC 保存时间，界面按配置的 `rewards.timeZone` 显示为 `MM-dd HH:mm`，默认 `Asia/Shanghai`；支持筛选、刷新、上一页、下一页、返回第一页，刷新保留当前筛选和翻页位置 |
| 管理员变动 | 两套界面均不提供账户变动输入、预览或确认。仅使用 /contribution add/remove 命令；旧 ui prepare/confirm 请求拒绝执行 |

安装模组的客户端采用服务端下发的结构化行数据和固定像素列，行业建设度、统计与流水表格的标题和数值可精确对齐，流水原因过长时在列内截断。原版 Dialog 无法保证空格排版的像素精度，后备页用内置等宽字体与固定显示列宽提供紧凑的单行记录。客户端页可点选“全部”“股票买入”“股票卖出”等常用筛选；原版流水页保留“全部流水”“股票买入”“股票卖出”“管理员调整”“退市返还”按钮。其他筛选仍可使用 `type/source/server/from/to` 的 `名称=值` 高级格式，与文字命令共享解析及权限。筛选日期仍按 UTC 日界线计算并包含结束日期；界面注明该区别。普通玩家只能查询本人最近 90 天；管理员可查历史归档，单次最多 365 天。查询其他玩家使用名称或 UUID，目标选择器仍由文字命令提供。

数据从当前数据库异步读取，不阻塞服务器线程；界面反映已提交的数据，统计正常有约 5 秒批量提交延迟。数据库不可用时显示错误页，按本地文件库或共享 MySQL 给出不同排查提示，不显示缓存余额冒充实时余额。单人和单服默认自动创建世界内嵌入式数据库；群组服连接共享 MySQL。客户端专用页的 Esc 返回固定上级（不使用浏览历史）；首页 Esc 退出。所有贡献页底部固定“返回上级、首页、关闭”，关闭立即退出并使旧查询失效。分页游标历史独立存储，只有“上一页”使用该历史，Esc 不返回上一页流水。原版子页的取消动作同样指向上级；股票详情/个人页指向市场，商店编辑指向商品管理，商品管理指向商店。纯页面导航不经过交易请求限流；异步查询返回时若玩家已经切到其他页面，则丢弃旧查询结果，避免覆盖新画面。

客户端页在存在输入框时为标签、输入框与表格标题分别预留垂直空间；操作按钮按网格居中排列，空白的管理员页面不显示“暂无记录”。

## 权限与提交

管理员权限使用原版管理员级别（通常 OP 等级 2）。服务端重新校验每个请求，隐藏按钮不是权限控制。未授权玩家手动输入内部页面命令，也不能查询他人或修改余额。

管理员余额调整仅通过文字命令执行，数量、布尔值、原因和备注遵循账户设计中的限制；图形页面不能绕过这些校验。旧图形预览令牌流程已移除。

交易与数据变更命令仍使用请求限流：每位玩家最多突发 8 次，正常每 10 tick 恢复 1 次，全服每 tick 最多接受 40 次。纯界面导航不占用该配额。

股票市场从贡献值首页分离，使用 `/stock` 打开；其曲线和买卖界面详见[股票系统](../extensions/stock.md)。商店独立使用 `/shop`，可选客户端提供商品图标与搜索界面，原版客户端使用原生 Dialog。签到仍从贡献值首页进入。

## 导航与布局

每位玩家只有一个服务端 PageSession，集中保存页面、导航、模式、请求间隔、版本及在途读取。异步结果必须同时匹配会话对象和页面版本；关闭/离服移除会话，旧请求即使完成也不能覆盖重新打开的页面。普通页面请求限流，返回/首页/关闭仍可执行，不对经济操作擅自取消或自动重试。

账户列表与活动行使用注册的 AbstractWidget 接收点击，支持悬停边框、手形光标和键盘聚焦；不依赖屏幕手写坐标判断。滚动时复用当前可见行控件。客户端将业务操作区和固定底部导航区分开；第一页的上一页、末页的下一页禁用，不改变其位置。首次流水页不显示无效的“第一页”，后续页可返回第一页。同一模块刷新、翻页、搜索复用同一 Screen 实例并更新数据/控件绑定，保留输入和焦点，不调用 setScreen 创建新页面。内容区按实际按钮行数计算，避免第三行按钮覆盖表格；窄屏流水按比例分配列宽，行业总览五列等宽。

合并账户页的账户摘要、原始操作统计和行业建设度分区绘制，超出高度时滚轮滚动并显示只读滚动条。客户端贡献页面不暂停单人世界；首页关闭会使服务器待完成的查询失效，防止迟到结果再次打开界面。


设计依据：[NN/g 层级导航](https://www.nngroup.com/articles/breadcrumbs/)强调层级路径不同于访问历史；[W3C 一致导航](https://www.w3.org/WAI/WCAG21/Understanding/consistent-navigation)要求重复导航维持顺序。实现采用固定上级、独立分页、固定关闭入口；不声称这是唯一适用的 UI 方案。
# 一次性武器皮肤客户端界面（0.2.1）

安装模组的客户端主手右键原初烟火之星，自动打开自适应宫格。卡片上方为大图，下方为名称；悬浮采用原生物品提示。点击卡片进入更大预览与确认，Esc返回列表，关闭直接退出。屏幕不暂停单人世界，翻页仅重排本地快照，服务端仍负责一次性定型及完整主手快照校验。未安装客户端模组的玩家保留Dialog，使用独立放大居中模型；预览不消耗物品。

宫格按可用高度优先安排多行，卡片高度上限120逻辑像素，不将单行卡片拉伸填满窗口。过矮窗口降为单行；右侧只读滚动条显示当前分页进度，滚轮及翻页按钮保持原有操作，不增加拖动行为。
