# 图形界面

贡献值 Basic 图形界面继续使用 Minecraft 26.3 原生 Dialog。服务端提供页面与数据，原版客户端负责绘制；无需安装客户端模组。股票和商店有独立的可选客户端专用界面，原版客户端分别使用 Dialog 后备界面。

输入 `/contribution` 或 `/contribution ui` 打开首页。文字命令与聊天分页保留，控制台继续使用文字命令。

## 页面

| 页面 | 内容与交互 |
| --- | --- |
| 首页 | 我的账户、我的流水、我的统计、行业建设度、每日签到与活动；管理员额外看到“管理员功能”入口。股票和商店分别由 `/stock`、`/shop` 打开。首页不放输入框，避免高界面缩放时页面贴近屏幕底部 |
| 签到 | 今日在线秒数与自动签到状态、活动期限和奖励；可点击领取活动奖励 |
| 管理员功能 | 账户列表、全服流水，以及通过名称或 UUID 查询玩家账户与统计；返回首页 |
| 账户 | 玩家名称、UUID、余额和历史总收入；链接到流水及玩家统计 |
| 玩家统计 | 原始放置、挖掘总次数及九个行业个人累计建设度 |
| 行业总览 | 九行业当日建设度、已结算总建设度、繁荣度及最后结算日，支持刷新 |
| 账户列表 | 管理员按名称分页，图形界面每页 8 个账户，可点击进入详情 |
| 流水 | 图形界面每页 8 条，显示 UTC 时间、玩家、变动、余额、类型、原因；支持筛选、下一页、返回第一页 |
| 管理员变动 | 账户页填写带符号的整数数量与原因，进入预览后确认；正数增加、负数扣除。当前图形页没有“影响历史总收入”开关，正数按默认规则计入、负数不计入；需要指定布尔值时使用管理员文字命令 |

流水页提供“全部流水”“股票买入”“股票卖出”“管理员调整”“退市返还”点选按钮。其他筛选仍可使用 `type/source/server/from/to` 的 `名称=值` 高级格式，与文字命令共享解析及权限。日期为 UTC，包含结束日期。普通玩家只能查询本人最近 90 天；管理员可查历史归档，单次最多 365 天。界面查询其他玩家使用名称或 UUID，目标选择器仍由文字命令提供。

数据从当前数据库异步读取，不阻塞服务器线程；界面反映已提交的数据，统计正常有约 5 秒批量提交延迟。数据库不可用时显示错误页，按本地文件库或共享 MySQL 给出不同排查提示，不显示缓存余额冒充实时余额。单人和单服默认自动创建世界内嵌入式数据库；群组服连接共享 MySQL。子页面底部提供“返回上一页”，Esc 使用原生 Dialog 的取消动作执行相同的返回命令；首页 Esc 关闭界面，不暂停世界。每名玩家最多记住最近 20 个页面跳转；主动返回首页会清空返回记录。返回命令也受与其他界面请求相同的限流约束。

## 权限与提交

管理员权限使用原版管理员级别（通常 OP 等级 2）。服务端重新校验每个请求，隐藏按钮不是权限控制。未授权玩家手动输入内部页面命令，也不能查询他人或修改余额。

管理员预览生成与操作者 UUID 绑定的确认令牌，有效期 5 分钟；每名管理员最多保留一个待确认操作。重复点击确认或“重试原请求”复用同一个幂等 ID。再次填写并预览代表新操作。令牌过期需要重新预览，不自动重发已经不确定的交易。

界面原因上限 64 字；完整服务端校验按 Unicode 码点计数，备注可通过文字命令或 API 提供。余额及历史总收入仍遵守账户上限，图形界面不提供绕过限制的入口。

所有图形请求与文字命令共享限流：每位玩家最多突发 8 次，正常每 10 tick 恢复 1 次，全服每 tick 最多接受 40 次。失败时显示“操作过快，请稍后重试”。

股票市场从贡献值首页分离，使用 `/stock` 打开；其曲线和买卖界面详见[股票系统](../extensions/stock.md)。商店独立使用 `/shop`，可选客户端提供商品图标与搜索界面，原版客户端使用原生 Dialog。签到仍从贡献值首页进入。
